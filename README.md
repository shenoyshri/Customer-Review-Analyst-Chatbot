# 💬 Customer Review Analyst Chatbot

A **Retrieval-Augmented Generation (RAG)** chatbot that lets you ask natural language questions about your customer reviews. Built with **SentenceTransformers**, **FAISS**, **Google Gemini 2.5 Flash**, and **Streamlit**.

---

## 🖼️ Demo

> Ask questions like:
> - *"Which product has the best reviews?"*
> - *"What are the most common complaints?"*
> - *"What do customers say about battery life?"*

The chatbot retrieves the most relevant reviews from your dataset and uses Gemini to craft a clear, conversational answer.

---

## 🏗️ Architecture

```
customer_reviews.csv
        │
        ▼
[ Jupyter Notebook ]
  • Load & preprocess reviews
  • Generate embeddings (all-MiniLM-L6-v2)
  • Build FAISS vector index
  • Save ──► faiss_index.pkl
           ► documents.pkl
                  │
                  ▼
          [ app.py — Streamlit ]
            │
            ├── User question
            ├── Embed question → FAISS similarity search
            ├── Retrieve Top-K review chunks
            ├── Build prompt with context + chat history
            └── Gemini 2.5 Flash → Answer
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/customer-review-chatbot.git
cd customer-review-chatbot
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the pickle files

Open `Customer_Review_Chat_Bot.ipynb` in Jupyter and run all cells. The last cell saves two files to your project folder:

```python
import pickle

with open("faiss_index.pkl", "wb") as f:
    pickle.dump(index, f)

with open("documents.pkl", "wb") as f:
    pickle.dump(documents, f)
```

After running, confirm you have both files in the project root:

```
faiss_index.pkl   ✓
documents.pkl     ✓
```

### 4. Get a Gemini API key

1. Go to [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Create a free API key
3. Keep it handy — you'll paste it into the app sidebar

### 5. Launch the app

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501`. Enter your Gemini API key in the sidebar and start chatting.

## 📊 CSV Format

Your `customer_reviews.csv` must contain at minimum these columns (names are flexible):

| Column | Example values |
|---|---|
| `product_id` | `SKU-001`, `Laptop Pro X` |
| `rating` | `1` – `5` |
| `review_text` | `"Great battery life, fast delivery…"` |

The notebook reads this file and constructs one text chunk per row:

```
Product: Laptop Pro X,
Rating: 5,
Review: Great battery life, fast delivery…
```

## 💡 Features

- **Multi-turn conversation** — retains the last 3 turns of chat history in every prompt
- **Adjustable Top-K** — tune how many reviews are retrieved per question (sidebar slider, 1–10)
- **Starter questions** — click-to-ask examples shown on a fresh chat
- **Retrieved context viewer** — expand to see exactly which reviews backed each answer
- **Clear chat** — reset the conversation any time from the sidebar

## 🚢 Deploying to Streamlit Cloud

1. Push the repo to GitHub (ensure `faiss_index.pkl` and `documents.pkl` are committed, **or** regenerate them in a setup step)
2. Go to [https://share.streamlit.io](https://share.streamlit.io) → **New app**
3. Select your repo and set **Main file** to `app.py`
4. Under **Advanced settings → Secrets**, add:
   ```toml
   GEMINI_API_KEY = "AIza..."
   ```
5. Click **Deploy**

> **Note:** If the pickle files are large, consider using [Streamlit Cloud's file storage](https://docs.streamlit.io/deploy/streamlit-community-cloud) or hosting them on Google Drive / S3 and downloading at startup.

## 🛠️ How It Works

1. **Indexing (notebook)** — Each review row is converted to a formatted text string. `SentenceTransformer` encodes all strings into 384-dimensional vectors. These are stored in a FAISS `IndexFlatL2` for fast nearest-neighbour search. Both the index and the raw strings are serialised as pickle files.

2. **Retrieval (app.py)** — The user's question is embedded with the same model. FAISS returns the Top-K most similar review vectors. Their corresponding text chunks form the context.

3. **Generation (app.py)** — A structured prompt is assembled containing the retrieved reviews, the last 3 turns of conversation history, and the current question. This is sent to Gemini 2.5 Flash, which returns a grounded, conversational answer.

## 🙋 FAQ

**Q: Can I use a different embedding model?**  
Change `MODEL_NAME` at the top of both the notebook and `app.py`. Make sure both use the same model — the index dimensions must match.

**Q: Can I use a different LLM instead of Gemini?**  
Yes. Replace the `ask_gemini` call in `app.py` with any OpenAI / Anthropic / Ollama API call. The prompt string stays the same.

**Q: The app says pickle files are missing.**  
Run the last cell of the notebook first, then make sure `faiss_index.pkl` and `documents.pkl` are in the same directory as `app.py`.
